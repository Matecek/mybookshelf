# MyBookShelf 

# Description:
Strona internetowa biblioteki książek
Projekt do samorozwoju 

# Run:
Aby uruchomić aplikację wystarczy sklonować repozytorium używając komendy git clone
Następnie uruchomić dockera na naszym komputerze docker compose up -d
Łącząc się na link http://localhost:8080/
